DESCRIPTION
-----------
Delivered an enterprise AI Knowledge Assistant integrated into an existing Angular and Java platform, introducing a Python FastAPI microservice without modifying the existing backend. The Angular app was extended with a user chat window and an admin portal for document ingestion and access-level management.

The core is a RAG pipeline orchestrated with LangGraph — an AI agent classifies each query and routes it to either document retrieval or a structured tool. Retrieval fetches permission-filtered content from a Qdrant vector store, then OpenAI GPT-4o generates answers grounded strictly in those documents, with text-embedding-3-small handling semantic search.

Security is layered: RBAC enforced at the vector query level across three document tiers, multi-layer guardrails covering prompt injection and off-topic filtering, and a post-generation LLM-as-judge hallucination check. Redis manages conversation memory and rate limiting across all stateless pods. An OpenAPI 3.0 contract with JWT authentication provides the Angular integration surface.

Deployed on Stackit with Kubernetes — horizontal autoscaling, Ingress load balancing, rolling zero-downtime deployments, Qdrant on a persistent volume, and LangSmith for end-to-end LLM tracing.
